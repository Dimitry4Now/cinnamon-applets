# App Menu

Shows the focused application's icon and name in the panel, like the app name next to the Apple menu on macOS. You always see what has focus.

Click it for:

- New Window (for apps that support it)
- Minimize, Maximize or Restore
- Always on Top, On All Workspaces
- Move to Workspace
- Close Window, Quit the app (closes all of its windows)

When no app window has focus, it shows **Desktop**, with shortcuts to your home folder and System Settings. Docks, launchers and other shell windows don't count as focus changes, so the last app stays shown while you use them.

## Settings

- Show the application icon (on by default)

Works best on a top panel, right after the menu applet.
